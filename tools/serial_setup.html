infoclock32 serial setup

Set Wi-Fi and clock settings over USB. Chrome or Edge on desktop.

This browser has no Web Serial API. Open the file in Chrome or Edge on a desktop computer.

1. Connect

Not connected

Plug the clock in, click Connect and pick its port (USB JTAG/serial debug unit, CP210x or CH340).

2. Wi-Fi

Forget Wi-Fi erases the network from the config and the Wi-Fi driver; after a reboot the clock opens its <hostname>-setup access point.

3. Clock settings

Only changed fields (outlined) are sent. Passwords are never read back: leave them empty to keep the current one. Most settings take effect after a reboot.

4. Any key

Config key reference (0 keys)
KeyDefaultDescription

Click a key to put it in the field above (and read its value when connected). <N> / <name> stand for a number or a name you choose. Generated from the README.

The full key list is in the project README (config_keys.js was not found next to this page).
